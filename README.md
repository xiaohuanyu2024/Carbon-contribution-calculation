# 双碳贡献力月报生成器

源码发布版 v1，更新说明：按中标月份筛选，月内按采购批次分别计算家次。

上传上月贡献力表、去年同期表，填写本月油量和电量，即可下载下一月报告。采购清单和电表文件可选。界面基于Streamlit，支持部署后多人通过浏览器使用。

## 上传GitHub

1. 解压源码包。
2. 登录GitHub，新建一个仓库，例如 `double-carbon-report`。
3. 打开仓库，选择 `Add file` → `Upload files`。
4. 上传解压目录内的文件，让 `app.py`、`core.py`、`requirements.txt`、`README.md` 位于仓库根目录。不要只上传ZIP压缩包。
5. 如网页上传未保留隐藏的 `.streamlit` 目录，可先省略它；不影响基本启动。`.gitignore`建议通过Git提交或在GitHub手动创建。
6. 提交文件。源码包没有真实业务Excel，无须上传业务文件到仓库。

## 在线部署

1. 登录Streamlit Community Cloud（https://share.streamlit.io/），关联GitHub。
2. 新建应用，选择上述仓库及对应分支。
3. 主程序路径填 `app.py`，Python建议选择3.11或3.12。
4. 点击部署，安装依赖后打开应用链接。
5. 同事通过应用链接上传文件并生成报告。

GitHub负责存源码，网页运行需要Streamlit或其他Python服务器；GitHub Pages不能运行此Python应用。

使用公开托管服务时，上传的工作簿会传至该服务进行处理。内部资料需按单位要求选择访问权限或改为内网部署；不要把真实工作簿提交到GitHub仓库。

## 本机或内网运行

需要Python 3.10及以上。在解压目录打开终端，依次执行：

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

打开终端显示的本机链接。内网共享可运行：

```powershell
python -m streamlit run app.py --server.address 0.0.0.0 --server.port 8501
```

运行期间终端保持打开；同事使用服务器IP及8501端口访问。

## 计算口径

- 月份按“中标日期”筛选，TBD/空日期不计入确定月份。
- 家次按“完整参与批次编号+公司名称”的唯一组合计数。同一批次内去重，不同批次之间不去重。
- 包次为各有效标包的投标供应商数之和；清单每一项目/分标行须对应一个标包。同一项目在重复工作表中重复出现只取一次，名单冲突则提示核对。
- 用“投标供应商”列，不用“推荐供应商”。
- 不提供采购清单时保留上月累计，页面标明尚未确认本月新增；不清空累计数。
- 用电表默认统计AL4、AL5、AL6，按本期与上期差额乘倍率；手填电量单位为kWh。
- 汽油升转吨系数0.00073；用电kWh转MWh系数0.001。
- 跨年1月累计从0开始。旧年辅助页月份记录会清空，新年度重新填入。
- 去年同期按指标名称匹配，兼容2025旧表的电量/汽油行号。不要上传其他月份充当去年同期。

本版沿用2026新版主表和标准“采购、油、电”辅助页。其他能耗及合同/单据累计沿用上月；若这些项目发生新增，应在生成表中补充。本版不提供这些扩展字段的网页输入。

## Excel结果

保留上月模板样式和公式，写入本月数值并设置打开时自动重算。请用Excel/WPS打开下载文件，重算后保存；部分只读取公式缓存的预览器在首次打开前可能显示空白计算结果。

下载文件名包含版本号和“按批次生成”说明；页面可指定版本。同一会话重复生成同月报告时版本自动递增。新会话不知道你本地已有的版本，请填写大于已保存版本的编号，避免覆盖正式旧版。

上传内容仅保留在当前应用会话内存中，不写入业务文件目录，不提供跨用户历史任务列表。关闭或重启会话后需重新上传；公网访问权限由部署平台设置。
